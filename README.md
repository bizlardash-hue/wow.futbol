# WOW.FUTBOL

An independent football media and statistics platform built with Next.js.

## Current status

The first milestone is an original responsive homepage and visual identity. Fixture cards and editorial cards are preview content only. They are not live scores or current football reporting.

## Technology

- Next.js 16
- React 19
- TypeScript
- Custom responsive CSS
- Vercel deployment

## Run locally

Requirements: Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy on Vercel

1. Sign in to Vercel.
2. Select **Add New → Project**.
3. Import `bizlardash-hue/wow.futbol` from GitHub.
4. Keep the detected Next.js framework preset.
5. Use the default build command: `npm run build`.
6. Deploy.
7. Add `wow.futbol` in the project's Domains settings after deployment, then apply the DNS records Vercel provides.
